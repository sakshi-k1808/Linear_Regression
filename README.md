# Linear_Regression


This repository contains a Jupyter Notebook demonstrating a basic implementation of **Linear Regression** using Python and relevant machine learning libraries. It is ideal for beginners who want to understand the foundations of linear regression through hands-on coding.

##  Notebook Contents

The notebook includes the following:

- **Introduction to Linear Regression**
- **Data Import and Exploration**
- **Data Preprocessing**
- **Model Training using Scikit-learn**
- **Model Evaluation (R² Score, MSE, etc.)**
- **Visualization of Results**

##  Technologies Used

- Python 3.x
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib / Seaborn
- Scikit-learn

##  Output

The notebook trains a linear regression model on a sample dataset and visualizes the fitted regression line along with predictions. Performance metrics such as R² score and mean squared error (MSE) are also displayed.

* R2 score - 90%
* adjusted_r2 - 89%
* MSE - 2.217151072541896
* MAE - 1.2114892606469103
